# 나라 그림 만드는 법 (두 형제 + 랜드마크)

퀴즈를 다 맞히면 받는 그림은 **크레파스로 그린 두 형제가 그 나라 랜드마크 앞에서 찍은 사진** 같은 그림이다.

## 처음 60개국 그림과 앞으로 추가하는 나라 그림의 차이

| | 처음 60개국 (2026-10-04) | 앞으로 추가하는 나라 |
|---|---|---|
| 만드는 법 | 아이와 배경을 한 장에 통째로 그림 | **캐릭터 그림(투명 PNG) + 사람 없는 배경**을 따로 그린 뒤 합성 |
| 아이 모습 | 그림마다 조금씩 다름 | 모든 나라에서 똑같음 |
| 다른 아이로 바꾸기 | 60장을 다시 그려야 함 | 사진 한 장으로 캐릭터만 다시 만들면 됨 (서비스로 열 때 쓸 방식) |

## 새 나라 그림 만들기

1. `dist/data/landmarks.js`에 나라를 추가한다. `name`에는 화면에 보일 이름을, `scene`에는 그림 설명을 영어로 적는다.
   ```js
   gr: { name: "파르테논 신전", scene: "the Parthenon temple on the Acropolis hill in Athens" },
   ```
   아이들이 서는 자리를 바꾸고 싶으면 `kids: { x: 0.45, bottom: 0.95, height: 0.5 }`를 더 적는다. 값은 그림 크기 대비 비율이고, 정하지 않으면 가운데 아래(0.5 / 0.965 / 0.56)에 선다.
2. 그림을 만든다. 나라 하나에 4~6분 걸린다.
   ```bash
   python tools/make-landmark-art.py art gr
   ```
   - 사람 없는 배경을 그린다 → `drafts/landmark-bg/gr.png`
   - 캐릭터를 얹는다 → `drafts/kids-landmarks/kid/gr.png`
   - 게임용 그림을 만든다 → `dist/assets/landmarks/gr.webp`와 `thumb/gr.webp`
   - 포즈(`vsign` / `jump` / `wave`)는 나라마다 돌아가며 정해진다. 직접 고르려면 `--pose jump`, 배경만 다시 그리려면 `--redo-bg`를 붙인다.
3. 만든 그림을 열어 보고, 랜드마크가 알아보기 쉬운지 확인한 다음 배포한다.

## 캐릭터 (다른 아이로 바꿀 때)

```bash
python tools/make-landmark-art.py characters --photo 아이사진.jpg
```
- 사진 한 장으로 포즈 3가지 캐릭터를 그려 `drafts/characters/`(`vsign.png`, `jump.png`, `wave.png`)에 저장한다.
- 그림체는 `drafts/kids-landmarks/kid/kr.png`(경복궁 그림)를 기준으로 맞춘다.
- 이후 `art`를 다시 실행하면 새 캐릭터로 합성된다. 배경은 이미 있으면 다시 그리지 않는다.

## 주의

- 아이 사진·캐릭터·원본 그림은 `drafts/`에만 둔다. 이 폴더는 `.gitignore`에 들어 있어 공개 저장소에 올라가지 않는다.
- 아이 사진은 그림 생성 서비스(Codex/OpenAI)로 보내진다. 서비스로 열 때는 보호자 동의와 사진 처리 방침을 먼저 정한다.
- Codex는 흰 배경을 부탁해도 투명 PNG로 줄 때가 있다. 스크립트가 두 경우를 모두 처리한다.
