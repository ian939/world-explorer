# 빙글빙글 세계탐험대 기획서

## 1. 제품 정의

아이가 지구본을 돌려 나라를 선택하고, 짧은 학습과 미션을 끝내면 세계지도의 물음표가 대표 그림으로 바뀌는 탐험·수집형 학습 게임이다.

- 대상: 한글을 읽을 수 있는 7~8세 어린이
- 핵심 감정: 시험을 푼다는 부담보다 새로운 곳을 발견하는 기쁨
- 한 나라 플레이 시간: 약 2~4분
- 권장 사용 환경: iPad 가로·세로 모드, 터치 브라우저
- 첫 버전의 목표: 지구본 탐색과 도감 완성의 재미 검증

## 2. 핵심 경험

```text
지구본 돌리기 → 물음표 선택 → 특징 3개 만나기 → 미션 → 도감 카드 해금 → 다음 나라 탐색
```

정답을 틀려도 점수를 잃거나 실패 화면으로 이동하지 않는다. 선택한 오답을 흐리게 표시하고 힌트를 보여 준 뒤 다시 선택하게 한다.

## 4. 화면 구조

### 지구본 탐험

- 첫 화면에서 놀이가 즉시 시작된다.
- 지구본은 한 손가락 드래그로 회전한다.
- 앞면에 있는 나라만 선택점이 나타난다.
- 미발견 나라는 `?`, 발견한 나라는 대표 아이콘으로 표시한다.
- 회전 버튼을 함께 제공해 드래그가 어려운 아이도 사용할 수 있게 한다.

### 나라 학습과 미션

- 나라 이름, 국기, 위치한 대륙을 먼저 보여 준다.
- 인사말·자연·동물·건축·문화 중 세 항목만 짧게 제시한다.
- 음성으로 이야기를 들을 수 있다.
- 미션은 관찰, 여행 준비, 동물 찾기, 소리와 인사, 모양 찾기 등으로 이름을 달리한다.

### 나의 세계도감

- 발견 전 카드는 `?`와 대륙 힌트만 보인다.
- 발견 후 국기, 나라 이름, 대표 장소, 대표 아이콘을 보여 준다.
- 열린 카드는 눌러서 학습 내용을 다시 볼 수 있다.

### 보호자 메뉴

- 아동 화면과 명확히 분리한다.
- 간단한 덧셈 확인 후에만 전체 진행 기록을 지울 수 있다.

## 5. 학습·문화 원칙

- 한 나라를 하나의 음식이나 복장으로 단정하지 않는다.
- “모든 사람이 그렇다”가 아니라 “이 지역에서 볼 수 있다”라고 표현한다.
- 국기 암기보다 위치, 자연, 인사, 생활을 함께 연결한다.
- 정답 속도와 연속 출석을 경쟁 요소로 사용하지 않는다.
- 나라별 핵심 정보는 확장 전 아동용 자료와 공신력 있는 출처로 재검수한다.

## 6. 아동 안전과 접근성

- 모든 주요 터치 목표는 최소 44×44 CSS 픽셀로 만든다.
- 핀치 확대, 더블 탭 확대, 텍스트 선택, 이미지 드래그, 길게 누르기 메뉴와 아동 화면의 복사·붙여넣기를 차단한다.
- 문서의 확대 금지 설정만 믿지 않고 비수동 터치·제스처 이벤트를 함께 사용한다.
- 한 손가락 스크롤과 정상적인 탭은 유지한다.
- 보호자 입력 영역에서는 텍스트 선택과 입력 동작을 허용한다.
- 키보드 포커스 표시, 의미 있는 버튼 이름, 모션 감소 설정을 지원한다.

## 7. 측정할 항목

실사용 테스트에서는 개인 식별 정보 없이 다음을 관찰한다.

- 아이가 설명 없이 지구본을 돌릴 수 있는가
- 물음표가 선택 가능한 요소임을 알아차리는가
- 첫 나라를 발견하기까지 걸리는 시간
- 도감으로 자발적으로 이동하는가
- 한 번에 몇 나라까지 즐겁게 탐험하는가
- 오답 힌트를 읽고 다시 시도하는가

## 8. 다음 확장 순서

1. 아이 3~5명 대상 사용성 관찰
2. 실제 국가 윤곽과 줌 단계 개선
3. 나라별 미션을 드래그·소리·퍼즐형으로 다양화
4. 대륙 배지와 ‘오늘의 세 나라’ 모드 추가
5. 보호자용 플레이 기록과 관심 주제 요약
6. 콘텐츠 검수 후 국가 수 확대

광고, 채팅, 외부 링크, 결제, 경쟁 순위는 아동용 첫 버전의 범위에서 제외한다.
